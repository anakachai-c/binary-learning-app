# Binary Learning App

เว็บแอปสำหรับเรียนรู้และฝึกแปลงเลขฐานสอง สร้างด้วย Next.js, TypeScript และ Tailwind CSS

## Features

- บทเรียนพื้นฐานเลขฐานสอง
- แบบฝึกหัดฐาน 2 ไปฐาน 10 และฐาน 10 ไปฐาน 2
- ระดับ Easy, Medium และ Hard
- สุ่มโจทย์ ตรวจคำตอบ และแสดงเฉลย
- บันทึกคะแนนใน Local Storage
- Responsive สำหรับมือถือและคอมพิวเตอร์

## Run locally

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## Deploy

Import Repository นี้ใน Vercel แล้วกด Deploy โดยไม่ต้องตั้งค่าเพิ่มเติม
